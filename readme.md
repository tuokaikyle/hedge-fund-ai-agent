# Hedge fund mini

Inspired by `ai-hedge-fund`, this project:
- is a simplified version of it
- is a mini educational course
- shows how a small agent system is built
- aims for a gentle learning curve
- shows the core logic only and deliberately keep it simple
- does not try to be super robust
- does not meant to be production-ready or give real financial advice 

## Run

```bash
uv sync
uv run python run.py --course 1 --ticker AAPL
uv run python run.py --course 2 --ticker AAPL
uv run python run.py --course 3 --ticker AAPL
```
